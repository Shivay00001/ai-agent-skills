# ScrapeGraphAI

ScrapeGraphAI is a web scraping Python library that uses Large Language Models (LLMs) and direct graph logic to create automated, AI-driven scraping pipelines for websites and local documents. It transforms websites into clean, organized data for AI agents and data analytics simply by specifying the target and prompt.

## When to Use This Skill
Use this skill when the user requires:
- Extracting specific information from websites or local documents (HTML, JSON, Markdown, XML).
- Building automated data extraction pipelines using LLMs.
- Replacing traditional CSS/XPath-based scrapers with prompt-based scraping.
- Using managed API or open-source solutions for scraping via AI.

## Capabilities and Integration
- **LLM Support**: Works with OpenAI, Groq, Azure, Gemini, MiniMax, or local models via Ollama.
- **Integrations**: LangChain, Llama Index, Crew.ai, Agno, CamelAI.
- **Low-code Frameworks**: Pipedream, Bubble, Zapier, n8n, Dify, Toolhouse.
- **MCP Server Support**: Available for direct integration with Agents.
- **Pipelines**: E.g., `SmartScraperGraph` to extract info from a single page given a user prompt and source URL.
