# goose

goose is a general-purpose AI agent that runs on your machine. Not just for code — use it for research, writing, automation, data analysis, or anything you need to get done.

A native desktop app for macOS, Linux, and Windows. A full CLI for terminal workflows. An API to embed it anywhere. Built in Rust for performance and portability.

goose works with 15+ providers — Anthropic, OpenAI, Google, Ollama, OpenRouter, Azure, Bedrock, and more. Connect to 70+ extensions via the Model Context Protocol open standard.

## When to Use This Skill
Use this skill when the user requires:
- An AI agent that can run on their local machine via CLI, API, or Desktop App.
- Executing workflows, research, data analysis, or automation using Goose.
- Connecting with MCP (Model Context Protocol) extensions using a local agent.

## Installation
For the CLI:
```bash
curl -fsSL https://github.com/aaif-goose/goose/releases/download/stable/download_cli.sh | bash
```

*Note: On Windows, it is recommended to download the Desktop App from https://goose-docs.ai/docs/getting-started/installation or use WSL for the bash installer.*
