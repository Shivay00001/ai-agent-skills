# GitHub Management Skill

This skill provides expertise in managing GitHub repositories, organizations, and workflows effectively.

## Core Capabilities

1. **Repository Setup & Standardization**:
   - Creating standardized `.github` templates (e.g., ISSUE_TEMPLATE, PULL_REQUEST_TEMPLATE).
   - Setting up branch protection rules and code owner definitions.

2. **CI/CD Pipeline Configuration (GitHub Actions)**:
   - Designing and implementing automated workflows for testing, linting, and deployment.
   - Optimizing workflow execution time and managing secrets.

3. **Issue & PR Management**:
   - Structuring issue labels, milestones, and project boards.
   - Performing automated or manual PR reviews, enforcing coding standards.
   - Managing triage processes for bug reports and feature requests.

4. **Release Management**:
   - Automating semantic versioning and release note generation.
   - Managing GitHub releases and tags.

## Usage Guidelines

- Always ensure that proposed GitHub Actions workflows use the latest stable versions of actions.
- When creating PR templates, include sections for descriptions, related issues, and testing steps.
- Recommend appropriate branch protection rules (e.g., requiring reviews, passing status checks) for production and main branches.
