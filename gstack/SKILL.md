# GStack Framework

**Repository:** [garrytan/gstack](https://github.com/garrytan/gstack)

Created by Y Combinator CEO Garry Tan, `gstack` is an open-source toolkit designed to enhance AI-assisted development by turning the AI agent into a "virtual engineering team."

## Key Concepts
- **Specialized Roles**: Uses slash commands to activate specific "cognitive modes," such as CEO (product strategy), Engineering Manager (architecture), Designer, QA Lead, and Security Officer.
- **CLAUDE.md Driven**: Relies on reading a central context file at the start of a session to establish project-specific rules and persona-driven behaviors.
- **Workflow breadth**: Covers the full product lifecycle from planning and design to shipping and retrospectives.

## Methodology
The framework emphasizes rigorous planning, code reviews, and automated testing before implementation to reduce "AI slop" and improve output quality. It encourages the agent to debate ideas from multiple perspectives before execution.

## When to Use
Use this skill when the user wants to take a structured, team-based approach to building software, requiring high-level product strategy, architectural review, and rigorous QA before shipping features.
